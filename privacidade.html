Política de Privacidade

Última atualização: 23 de novembro de 2026

Quem somos

Content Factory ("apiyou") é uma ferramenta pessoal operada por Gustavo Passos (gugu.passos@gmail.com) para publicar vídeos nos canais de sua propriedade.

Serviços de API do YouTube

Este aplicativo usa os Serviços de API do YouTube. Ao usá-lo, você concorda com os Termos de Serviço do YouTube. Consulte também a Política de Privacidade do Google.

Quais dados acessamos

Somente da conta Google que autoriza o app: o token de autorização OAuth, o ID e o nome do canal, e os metadados dos vídeos enviados pelo próprio app (título, descrição, status, estatísticas públicas). Não acessamos dados de outros usuários, e-mails, contatos ou pagamentos.

Como usamos

Exclusivamente para enviar e agendar vídeos e acompanhar o desempenho dos canais do próprio dono. Os dados não são vendidos, compartilhados ou usados para publicidade.

Armazenamento e segurança

Os tokens ficam armazenados apenas no servidor do dono, com acesso restrito. Os dados de vídeo são mantidos enquanto forem necessários para a operação dos canais.

Como revogar o acesso

Você pode revogar o acesso a qualquer momento em Permissões da Conta Google. Para pedir a exclusão dos dados armazenados, escreva para gugu.passos@gmail.com; a exclusão é feita em até 7 dias.

Cookies

Este site e o aplicativo não usam cookies de rastreamento.

English summary

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service; see the Google Privacy Policy. It only accesses the authorizing account's OAuth token, channel ID/name and the metadata of videos it uploads, solely to upload, schedule and monitor the owner's own channels. Data is never sold or shared. Tokens are stored only on the owner's server. Revoke access at Google Account permissions; request deletion at gugu.passos@gmail.com (completed within 7 days).
